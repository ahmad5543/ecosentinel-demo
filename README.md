# EcoSentinel Demo

A browser-based, interactive concept dashboard for the EcoSentinel project.

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a public repository named `ecosentinel-demo` (or another name).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for the published URL to appear on the Pages settings screen.

## Important disclosure
This is a simulation only. It does not record audio, run an AI model, or connect to physical sensors. The values and alerts are scripted examples for demonstrating the proposed workflow.
